# Code of Conduct

JTetris aims to be a useful, readable Java project for learning, experimentation, and code-quality practice.

Contributors are expected to:

- Be respectful and constructive in issues, pull requests, and reviews.
- Focus feedback on code, design, behavior, and documentation rather than people.
- Keep discussions relevant to the project.
- Avoid harassment, personal attacks, discriminatory language, or repeated disruptive behavior.

Project maintainers may close comments, issues, or pull requests that do not follow these expectations. For conduct concerns, contact Yuan Jiang at sleetdrop@gmail.com.
