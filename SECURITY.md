# Security Policy

JTetris is a small learning and showcase project. It is not security-critical software and does not currently provide a formal private vulnerability disclosure program.

If you find a security issue, please report it by opening a GitHub issue or by contacting Yuan Jiang at sleetdrop@gmail.com. Avoid including sensitive personal data or exploit details beyond what is needed to reproduce the problem.

Security reports will be handled on a best-effort basis.
