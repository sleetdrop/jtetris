# M4.3 Score Breakdown Panel Spec

## Spec ID
`M4.3-SCORE-BREAKDOWN-PANEL`

## Status
`Done`

## Scope
- Display score-event breakdown state in the side panel.
- Surface latest scoring event, combo streak, and B2B status for learning/debugging.
- Keep model scoring rules unchanged.

## Out of scope
- Animated score popups.
- Color/FX severity coding by event type.
- Localization of score-event labels.

## Design notes
- Reuse `Board` getters introduced in M4.2.
- Show compact text entries to keep side panel readable.
- Use placeholder `-` for no-clear/none events.

## Implementation checklist
- [x] Add score-breakdown labels to `SidePanel` stats block.
- [x] Refresh event/combo/B2B labels on timer-based panel refresh.
- [x] Keep controls and hold/next preview layout stable.
- [x] Update docs and roadmap/context records.
- [x] Run regression test suite.

## Acceptance criteria
- Side panel shows latest event, combo value, and B2B on/off state.
- Display updates after each lock/clear cycle.
- Existing gameplay mechanics and tests remain stable.

## Verification
- Manual: play several clears and confirm event/combo/B2B text changes.
- Automated: `mvn clean test` regression pass.

## Rollback plan
- Remove added labels from `SidePanel` and revert to score/level/lines only.
- Keep model scoring state for future UI work.
