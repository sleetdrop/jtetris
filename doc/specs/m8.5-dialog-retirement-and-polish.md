## Out of scope
- New gameplay features.
- Score storage format changes.

## Design notes
- Remove no-longer-needed `JOptionPane` wrapper/default-tuning helpers.
- Centralize overlay style tokens (surface/border/text/accent states) for light/dark.
- Keep interactions keyboard-first and visually consistent with stage aesthetic.
- Keep transition language consistent: short fade + subtle slide on overlay show/hide.

## Implementation checklist
- [ ] Remove obsolete `JOptionPane` helper code and imports.
- [ ] Consolidate overlay style constants and rendering rules.
- [ ] Tune spacing/contrast/focus ring for readability in both themes.
- [ ] Update docs where behavior moved from dialogs to stage overlays.

## Acceptance criteria
- Core prompt flows are fully stage-based.
- No remaining hard dependency on `JOptionPane` in primary user flows.
- Overlay visuals are consistent across light/dark modes.
- Overlay motion is consistent and brief across all stage prompt types.
