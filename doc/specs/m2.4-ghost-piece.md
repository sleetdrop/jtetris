# M2.4 Ghost Piece Spec

## Spec ID
`M2.4-GHOST-PIECE`

## Status
`Done`

## Scope
- Render a ghost projection for active piece landing position.
- Keep projection non-interactive and visual-only.
- Ensure projection updates on move/rotate/drop each frame.

## Out of scope
- Theme/palette redesign.
- Accessibility options for ghost styling.

## Design notes
- Ghost y-position is computed by simulated downward movement until collision.
- Ghost must never modify board state.
- Hard drop final lock position should match ghost landing position.

## Implementation checklist
- [x] Add projection computation method in model or rendering helper.
- [x] Render ghost layer before active piece drawing.
- [x] Ensure ghost is hidden when game over or no active piece.
- [x] Verify no overlap artifacts with placed blocks.
- [x] Document ghost semantics in `doc/overview.md`.

## Acceptance criteria
- Ghost always indicates hard-drop destination accurately.
- Ghost updates immediately after move/rotate.
- No gameplay behavior changes due to ghost rendering.

## Verification
- Manual: pending GUI smoke check for ghost visibility/readability.
- Automated: `GhostPieceTest` validates non-mutating projection and hard-drop landing match.

## Rollback plan
- Keep ghost rendering behind UI toggle.
- If render artifacts occur, disable ghost while preserving model changes.
