## Design notes
- Replace `promptNewGame()` and score-entry dialog chain with staged overlays.
- Keep current score logic and `ScoreManager` contract unchanged.
- Overlay style follows HUD-in-stage panels without full-screen dim mask.
- During score/game-over overlays, gameplay logic remains paused while board stays visible.
- Overlay panel uses bounded adaptive sizing (content-based with min/max guardrails).
- Score entry panel supports:
  - Existing user selection list.
  - New user text input.
  - Keyboard navigation and submit/cancel actions (`Enter`/`Space` confirm, `Esc` cancel).
- Preserve one-prompt-per-game-over semantics.
