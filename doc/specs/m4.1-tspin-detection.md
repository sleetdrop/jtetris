# M4.1 T-Spin Detection Spec

## Spec ID
`M4.1-TSPIN-DETECTION`

## Status
`Done`

## Scope
- Add baseline T-Spin detection in model layer.
- Track whether the last lock was a T-Spin for future scoring/UI usage.
- Keep existing score values unchanged in this step.

## Out of scope
- T-Spin Mini differentiation.
- T-Spin-specific scoring multipliers.
- Combo/B2B interactions.

## Design notes
- Baseline rule: T piece + last successful action is rotation + at least 3 of 4 pivot corners occupied by wall/stack.
- Corner occupancy checks include out-of-bounds side/bottom walls as occupied.
- Detection is evaluated at lock time and stored as last-lock state.
