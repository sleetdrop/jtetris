## Design notes
- Keep visual changes localized to UI package and avoid model impacts.
- Detect theme mode from `jtetris.theme` system property first (`light|dark|auto`), then fallback to OS/LAF luminance heuristic.
- Bundle Inter fonts (SIL OFL 1.1) in resources with license file and fallback to logical fonts when loading fails.

## Implementation checklist

## Acceptance criteria
- Application starts with either light or dark palette based on OS/LAF (or explicit `-Djtetris.theme=` override).
- Core UI uses bundled Inter fonts when available, with safe fallback behavior.
- Dialogs and leaderboard presentation no longer use ad-hoc hardcoded dark gray defaults.
