# M2.2 SRS Rotation + Wall Kick Spec

## Spec ID
`M2.2-SRS-ROTATION-KICKS`

## Status
`Done`

## Scope
- Implement SRS-style rotation behavior for all tetrominoes.
- Add wall kick offsets for rotation retries near boundaries/blocks.
- Keep rotation controls and UI prompts unchanged.

## Out of scope
- Input timing tuning (DAS/ARR in M3).
- T-Spin scoring rules (M4).

## Design notes
- Use piece-specific kick tables where required (notably I-piece).
- Rotation succeeds on first valid kick candidate.
- Rotation fails only when all kick tests fail.

## Acceptance criteria
- Rotations near walls can succeed via valid kick offsets.
- I-piece kick behavior follows dedicated table rules.
- No illegal overlap/out-of-bounds state after successful rotate.
