# M8.1 FlatLaf Bootstrap and Theme Bridge

## Spec ID
- `m8.1-flatlaf-bootstrap-and-theme-bridge`

## Status
- `Done`

## Scope
- Goal:
  - Introduce FlatLaf as the Swing Look-and-Feel baseline and bridge runtime theme switching with existing `UiTheme` modes.
- File allowlist (exact paths):
  - `pom.xml`
  - `src/main/java/net/vetcafe/jtetris/ui/TetrisFrame.java`
  - `src/main/java/net/vetcafe/jtetris/ui/UiTheme.java`
  - `doc/specs/m8.1-flatlaf-bootstrap-and-theme-bridge.md`

## Out of scope
- Replacing dialogs with stage overlays.
- Model-layer gameplay or scoring changes.

## Design notes
- Keep `UiTheme` as the game-surface theme source (board/palette/custom paint).
- Use FlatLaf for Swing-native component consistency (menus, fields, tables, buttons).
- Preserve startup override contract: `-Djtetris.theme=auto|light|dark`.
- Runtime `Theme` menu updates both `UiTheme` and FlatLaf mode.

## Implementation checklist
- [x] Add FlatLaf dependencies in `pom.xml`.
- [x] Install FlatLaf before Swing components are created.
- [x] Update runtime theme switch path to keep `UiTheme` and FlatLaf in sync.
- [x] Validate menu/dialog/control rendering in light/dark/auto modes.

## Acceptance criteria
- App starts with FlatLaf style on supported platforms.
- `Theme` menu switches light/dark/auto at runtime without restart.
- Existing board/piece custom drawing remains unchanged in behavior.
