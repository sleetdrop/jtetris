# M8.4 Stage Leaderboard and Exit Confirm

## Spec ID
- `m8.4-stage-leaderboard-and-exit-confirm`

## Status
- `In-Progress`

## Scope
- Goal:
  - Move leaderboard display and exit confirmation from `JOptionPane` to in-stage overlays.
- File allowlist (exact paths):
  - `src/main/java/net/vetcafe/jtetris/ui/TetrisFrame.java`
  - `src/main/java/net/vetcafe/jtetris/ui/GamePanel.java`
  - `src/main/java/net/vetcafe/jtetris/ui/*` (overlay and stage panel UI classes)
  - `doc/specs/m8.4-stage-leaderboard-and-exit-confirm.md`

## Out of scope
- FlatLaf bootstrap and theme bridge.
- Game-over score-entry flow.

## Design notes
- Leaderboard panel remains read-only and keyboard-dismissible.
- Exit confirm panel maps to current YES/NO semantics.
- Keep existing key mappings (`L`, `Esc`) and focus behavior.
- Apply unified overlay key contract: `Enter`/`Space` confirm, `Esc` cancel/dismiss.
- Use bounded adaptive overlay sizing so leaderboard can expand while confirm panels stay compact.

## Implementation checklist
- [x] Add stage leaderboard overlay panel.
- [x] Add stage exit confirmation overlay panel.
- [x] Connect existing menu/key actions to overlay actions.
- [ ] Remove `JOptionPane` usage for leaderboard and exit confirmation.

## Acceptance criteria
- Pressing `L` shows leaderboard inside stage with current score data.
- Pressing `Esc` shows in-stage exit confirmation and respects current quit behavior.
- No regression in focus recovery after close.
