# M2.3 Hold Piece Spec

## Spec ID
`M2.3-HOLD-PIECE`

## Status
`Done`

## Scope
- Add hold slot with one hold action per active piece lifecycle.
- Support first-time hold (store current and spawn next).
- Support swap hold/current after first hold is populated.

## Out of scope
- Hold bonus scoring.
- Additional key rebinding UI.

## Design notes
- `holdUsedThisTurn` should reset only after current piece locks.
- Hold action should preserve fairness and not skip lock rules.
- UI side panel should display hold slot consistently.

## Implementation checklist
- [x] Add hold state to board model.
- [x] Add one-hold-per-turn guard.
- [x] Integrate hold display in side panel.
- [x] Define spawn orientation/position after swap.
- [x] Update control help text if key binding changes.

## Acceptance criteria
- First hold stores current piece and spawns next piece.
- Subsequent hold in same turn is ignored.
- After lock, hold becomes available again.

## Verification
- Manual: pending GUI smoke check for hold preview and in-game hold timing.
- Automated: `mvn clean test` passes `HoldPieceTest` plus existing model/UI-adjacent tests.

## Rollback plan
- Gate hold behavior behind a boolean feature flag in model.
- Revert to no-hold path if swap introduces top-out regressions.
