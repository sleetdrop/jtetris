# Release JTetris 1.0.0

## Why
JTetris is ready for its initial public GitHub release. The release should use a stable version number and publish artifacts that users can run on Java 17 or Apple Silicon macOS.

## What Changes
- Set the Maven project version to `1.0.0` for release artifacts.
- Build and publish the runnable jar plus runtime dependencies.
- Build and publish an Apple Silicon macOS app image archive.
- Tag the release commit as `v1.0.0` and create a GitHub Release.

## Impact
- Release metadata and artifact names become stable for the initial public release.
- No gameplay, UI behavior, dependency, package, or workflow behavior changes are intended.
